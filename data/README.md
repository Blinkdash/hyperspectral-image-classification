# Dataset files

The datasets are intentionally not included in the repository.

Place the Salinas files here:

- `Salinas_corrected.mat`
- `Salinas_gt.mat`

For Pavia Centre, the notebook accepts several common filename variants. The simplest pair is:

- `Pavia.mat`
- `Pavia_gt.mat`

The notebook expects the original hyperspectral cube and the corresponding ground-truth labels.
